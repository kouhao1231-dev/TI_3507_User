# GitHub 下载导入与 Keil 工程打开教程

本文档用于拍摄“学生拿到 GitHub 链接以后怎么下载、解压、打开 Keil 工程”的教程。重点不是讲 Git 原理，而是让新手能从链接一路走到 Keil 编译。

## 1. 这条视频要讲清楚什么

本视频只讲四件事：

1. GitHub 仓库页面在哪里下载。
2. 新手优先用 `Download ZIP`，不强制装 Git。
3. 下载后要先解压，不要直接在压缩包里打开工程。
4. Keil 不是打开文件夹，而是打开 `.uvprojx` 工程文件。

## 2. 开场口播

```text
这一节讲学生拿到 GitHub 仓库以后怎么下载和导入。新手不用先学 Git 命令，也不用自己重新创建 Keil 工程。我们直接从 GitHub 下载 ZIP，解压以后找到 Keil-only 工程文件夹，双击 .uvprojx 或者在 Keil 里 Open Project 打开它，然后直接 Rebuild。
```

## 3. 拍摄前准备

拍摄前桌面上建议准备一个干净目录，例如：

```text
桌面\TI_教程演示
```

不要直接在原工程目录里演示，避免学生看不出“下载、解压、打开”的完整流程。

需要打开的软件：

- 浏览器
- 文件资源管理器
- Keil uVision

## 4. GitHub 页面下载怎么拍

镜头：浏览器打开 GitHub 仓库主页。

操作步骤：

1. 指到仓库名称，说明这是项目主页。
2. 找到绿色或灰色的 `Code` 按钮。
3. 点击 `Code`。
4. 点击 `Download ZIP`。
5. 等待浏览器下载完成。

口播：

```text
进入 GitHub 仓库以后，先不要乱点文件。我们找到 Code 按钮，点开以后选择 Download ZIP。这个方式适合第一次上手的同学，不需要安装 Git，也不需要配置账号。
```

补一句：

```text
如果以后会用 Git，也可以用 clone，但新手教程里我们优先讲 ZIP 下载，减少环境问题。
```

## 5. 解压怎么拍

镜头：文件资源管理器打开下载目录。

操作步骤：

1. 找到下载好的 `.zip` 文件。
2. 右键选择“全部解压缩”或“解压到当前文件夹”。
3. 解压到一个路径简单的位置，例如桌面。
4. 打开解压后的文件夹。

口播：

```text
下载完成以后一定要先解压。不要直接在压缩包里双击工程文件，因为 Keil 编译时还要生成 Objects、Listings、hex 等文件，压缩包里面不能正常写入这些内容。
```

强调路径：

```text
建议路径不要太深，也不要放在中文特别复杂或者带很多特殊符号的目录里。比如放在桌面或者 D 盘的 TI_Project 文件夹里就可以。
```

## 6. 找到 Keil-only 文件夹

镜头：打开解压后的项目根目录。

要找的文件夹：

```text
Dianfu_TI_G3507_Keil_Only
```

口播：

```text
解压以后，学生主要打开这个 Keil-only 文件夹。这个文件夹是已经配好的 Keil 工程，和原来的源码资料、教程资料分开，避免 Keil 文件和 VS Code 文件混在一起。
```

拍摄时可以把鼠标停在这个文件夹上 2 秒，让观众看清名字。

## 7. 打开 Keil 工程

进入：

```text
Dianfu_TI_G3507_Keil_Only
```

找到：

```text
DCAR_G3507_User.uvprojx
```

两种打开方式都可以拍：

| 方法 | 操作 |
|---|---|
| 方式一 | 直接双击 `DCAR_G3507_User.uvprojx` |
| 方式二 | 先打开 Keil，再点 `Project -> Open Project...`，选择 `.uvprojx` |

口播：

```text
注意，Keil 打开的不是文件夹，而是工程文件。这里要打开的是 DCAR_G3507_User.uvprojx。如果你在 Keil 里点 Open，发现不能选中文件夹，这是正常的，因为 Keil 要选的是工程文件。
```

## 8. 编译验证怎么拍

镜头：Keil 工程打开后，拍左侧工程树和上方工具栏。

操作步骤：

1. 点击 `Rebuild`。
2. 等待编译完成。
3. 拍底部 Build Output。
4. 指出 `0 Error(s)`。
5. 指出已经生成 `.axf` 和 `.hex`。

口播：

```text
工程打开以后，先点 Rebuild。只要最后显示 0 Error，就说明工程编译通过。Warning 不是失败，真正影响的是 Error。这里已经生成 axf 和 hex，后面就可以进入下载烧录步骤。
```

如果还有 warning，可以这样说：

```text
有些 warning 来自官方库或备用函数，不影响本次编译下载。我们先看 Error，只要是 0 Error，工程就是编译通过的。
```

## 9. 下载烧录怎么讲

如果现场车能烧录：

```text
编译通过以后，连接调试器和核心板，确认供电正常，再点击 Download。下载完成以后复位或者重新上电，就可以运行程序。
```

如果现场车暂时烧录不上：

```text
当前这辆车暂时烧录不上，所以这条视频先演示 GitHub 下载、解压、打开 Keil 工程和编译通过。烧录不上一般要继续检查供电、调试器、SWDIO/SWCLK、GND、Keil Debug 配置，后面单独做排查。
```

## 10. 学生最容易犯的错误

拍摄时最后可以集中讲一遍：

| 错误 | 正确做法 |
|---|---|
| 下载后不解压，直接在 ZIP 里打开 | 必须先解压 |
| 在 Keil 里想选择整个文件夹 | Keil 要打开 `.uvprojx` 文件 |
| 打开了原始资料文件夹，不知道哪个是工程 | 打开 `Dianfu_TI_G3507_Keil_Only` |
| 路径太深或放在奇怪目录 | 放到桌面或 D 盘简单路径 |
| 只看 warning 就以为失败 | 重点看 `0 Error(s)` |
| 下载失败就以为工程坏了 | 下载失败通常先查供电、调试器和 SWD 接线 |

## 11. 给会 Git 的同学补充

这段可选，不必展开讲太久。

```text
如果你已经会用 Git，也可以复制仓库 HTTPS 地址，在电脑上执行 git clone。clone 下来的文件夹和 ZIP 解压后的内容基本一样，后面同样是进入 Keil-only 文件夹，打开 .uvprojx。
```

命令示例：

```powershell
git clone 仓库地址
```

不建议在新手视频里重点讲分支、提交、推送，避免跑题。

| 10 | 总结常见错误 | 30 秒 |
