# Gray8 八路灰度传感器测试说明

目标传感器：`感为无 MCU 八路灰度`，模拟量输出版本，内部通过 `74HC4051` 多路选择器切换 8 路通道。

## 当前测试接线

当前测试固件使用下面这组线：

| 传感器引脚 | MSPM0G3507 引脚 | 说明 |
|---|---|---|
| `+V` | `5V` | 使用稳定 5V |
| `GND` | `GND` | 必须和主控共地 |
| `OUT` | `PB25` | `ADC0_CH4` |
| `AD0` | `PB18` | 4051 地址位 0 |
| `AD1` | `PB24` | 4051 地址位 1 |
| `AD2` | `PB17` | 4051 地址位 2 |
| `EN` | 悬空或拉低 | 低电平/默认使能 |
| `ERR` | 不接 | 当前测试不用 |

## 当前固件行为

- 当前测试固件关闭 UART 测试显示，OLED 用一排 8 个圆点显示灰度状态。
- 初始化后会调用 `Dcar_Stop()`，不会主动跑运动序列。
- `Gray8_Task()` 按 100 Hz 扫描 `CH1..CH8`。

## OLED 直观显示

OLED 当前显示方式：

```text
GRAY8 TEST
1○ 2○ 3○ 4○ 5○ 6○ 7○ 8○
```

实际屏幕上每一路都是“数字编号 + 图形圆点”放在同一行：

- 空心圆圈：该路 bit 为 `0`
- 实心圆点：该路 bit 为 `1`
- 从左到右对应 CH1 到 CH8

这个显示由 `BoardOled_ShowGray8Dots(mask)` 完成。
这个接口要保留下来，后续八路灰度屏幕程序继续复用它，不再退回到只显示十六进制数值的方式。
当前校准值只是临时值，后续固定传感器高度后再重新校准。

当前测试固件为了让未校准状态也能看出变化，OLED 暂时显示 `Gray8_GetTestMask()`：

- 上电后先记录每一路的初始 raw 值作为背景。
- 之后某一路 raw 和背景差值超过临时阈值，就把该路圆点画成实心。
- 如果复位/上电时探头已经被遮挡，它会把遮挡状态当成背景，所以测试时建议先无遮挡复位一次。
- 正式巡线时仍应使用校准后的 `g_gray8.digital`，不要把这个测试 mask 当成最终巡线判断。

## VS Code 调试建议观察变量

在 Watch 窗口里添加：

```c
g_gray8.raw[0]
g_gray8.raw[1]
g_gray8.raw[2]
g_gray8.raw[3]
g_gray8.raw[4]
g_gray8.raw[5]
g_gray8.raw[6]
g_gray8.raw[7]
g_gray8.normalized[0]
g_gray8.digital
g_gray8.sample_count
g_gray8.timeout_count
g_gray8.last_error
g_gray8_calib_cmd
```

正常现象：

- `sample_count` 持续增加，说明采样在跑。
- `timeout_count` 应保持为 `0`。
- `last_error` 应保持为 `0`。
- 遮挡某一路探头时，对应 `raw[i]` 应变化。
- `digital` 的 bit0..bit7 对应 CH1..CH8；校准后一般 `1` 表示白，`0` 表示黑。

## 校准流程

校准值先存在 RAM 里。确认数值合理后，再复制进 `User/user_main.c` 的默认数组。

1. 把 8 路探头都放在白底上，保持最终安装高度。
2. 等 `g_gray8.raw[0..7]` 稳定。
3. 在调试器里设置：

```c
g_gray8_calib_cmd = 1
```

这会把当前 `raw[]` 复制到 `g_gray8.white[]`。

4. 把 8 路探头都放在黑线上，保持同样高度。
5. 等 `g_gray8.raw[0..7]` 稳定。
6. 在调试器里设置：

```c
g_gray8_calib_cmd = 2
```

这会把当前 `raw[]` 复制到 `g_gray8.black[]`。

7. 观察：

```c
g_gray8.white[0..7]
g_gray8.black[0..7]
g_gray8.span[0..7]
g_gray8.normalized[0..7]
g_gray8.digital
```

8. 如果某一路 `span[i]` 太小，说明这一路黑白对比不够。检查传感器高度、角度、供电、环境光、安装位置。
9. 数值确认后，把校准结果写回 `User/user_main.c`：

```c
static const uint16_t g_gray8_white[GRAY8_CHANNELS] = {...};
static const uint16_t g_gray8_black[GRAY8_CHANNELS] = {...};
```

然后重新编译烧录。

## 注意事项

- 代码支持两种极性：白色电压高于黑色可以，黑色电压高于白色也可以。
- 强阳光可能让传感器饱和，甚至导致黑白关系反过来。测试时尽量遮挡直射强光。
- 传感器供电要稳定。电机噪声可能导致 `raw[]` 跳动。
