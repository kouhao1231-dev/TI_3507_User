# 灰度模块快速测试说明

本测试只针对当前这辆车采用的灰度模块方案：`DAT + CLK` 数字通信。

不要按历史分线方案去接底板光电接口；本车不考虑那种接线。

## 1. 测试前确认

先确认四件事：

1. 模块供电电压是否正确。
2. `GND` 是否和主控共地。
3. `DAT` 是否接到代码里的 `SDA`。
4. `CLK` 是否接到代码里的 `SCL`。

拍摄和教学时只讲 `VCC/GND/DAT/CLK` 这组线。

## 2. 固件行为

当前灰度模块代码使用：

```text
User/Inc/digital_gray8.h
User/Src/digital_gray8.c
```

主要流程：

```c
DigitalGray8_Init();
DigitalGray8_SetAddress(DIGITAL_GRAY8_DEFAULT_ADDR);
DigitalGray8_Task10Hz();
uint8_t mask = DigitalGray8_GetMask();
```

如果模块地址不确定，可以先扫描地址：

```c
DigitalGray8_ScanAddress(0x08, 0x77);
```

## 3. 现场测试方法

如果车能烧录：

1. 打开 Keil 工程。
2. Rebuild 确认 `0 Error`。
3. Download 到核心板。
4. 观察 OLED 或串口输出的灰度状态。
5. 用手遮挡、用黑白底切换，确认状态会变化。

如果当前车暂时烧录不上：

1. 只拍模块上电。
2. 拍手靠近或遮挡探头。
3. 拍模块指示灯变化。
4. 说明程序读取效果等烧录恢复后补拍。

## 4. 常见问题

如果模块没有反应，优先检查：

- `VCC` 是否接对。
- `GND` 是否共地。
- `DAT/CLK` 是否接反。
- 模块本身指示灯是否会随黑白变化。
- 模块地址是否和代码默认地址一致。

## 5. 明确不要做

本车教程里不要做这些事：

- 不要讲历史分线方案。
- 不要展示某一路光电接口对应某个 MCU 引脚的表。
- 不要把感为灰度讲成模拟量扫描。
- 不要让学生照着历史分线方案去接。
