# 3507 小车用户交付包

这个文件夹是给新手用户直接使用的交付资料。建议按下面顺序阅读，不要一上来直接翻源码。

## 1. 先看快速开始

| 文件夹 | 作用 |
|---|---|
| `01_新手快速开始` | VS Code 编译烧录、八路灰度快速测试 |
| `02_模块使用教程` | 每个模块怎么接线、怎么调用、怎么测试 |
| `03_API参考` | API 总表、引脚修改、外设配置细节 |
| `04_封装源码` | 可以复制进工程的 `Inc` 和 `Src` 封装文件 |

## 2. 推荐阅读顺序

1. `01_新手快速开始/01_VSCode配置编译烧录说明.md`
2. `02_模块使用教程/01_OLED屏幕.md`
3. `02_模块使用教程/02_五个按键.md`
4. `02_模块使用教程/03_蜂鸣器.md`
5. `02_模块使用教程/04_UART串口.md`
6. 按实际传感器选择：
   - 感为科技：`02_模块使用教程/05_感为科技八路灰度.md`
   - 亚博智能：`02_模块使用教程/06_亚博智能八路灰度_UART.md`
7. 需要查完整函数时，再看 `03_API参考/01_用户模块API使用说明.md`

## 3. 源码怎么放进工程

交付源码在：

```text
04_封装源码/Inc
04_封装源码/Src
```

复制到点浮工程时，对应放到：

```text
TI_3507_User/User/Inc
TI_3507_User/User/Src
```

如果当前工程里已经有同名文件，先确认是不是旧版本，再覆盖。
