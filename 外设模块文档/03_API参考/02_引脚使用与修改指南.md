# 引脚占用与改线指南

本文档只记录当前教程实际采用的用户侧外设。历史分线方案不作为本车方案，不在这里提供接线表。

## 当前用户侧模块

| 模块 | 信号 | 代码归属 | 说明 |
|---|---|---|---|
| OLED | `OLED_SDA / OLED_SCL` | `board_oled.c` | 屏幕显示 |
| 按键 | `KEY1..KEY5` | `board_keys.c` | 五个底板按键 |
| 蜂鸣器 | `BUZZER_IO` | `board_buzzer.c` | 声音提示 |
| UART | `TX / RX` | `board_uart.c` | 串口调试或 UART 模块 |
| 感为灰度 | `DAT / CLK` | `digital_gray8.c` | 软件 IIC 数字通信 |
| 亚博灰度 UART | `TX / RX` | `yabo_gray8_uart.c` | UART 灰度模块 |

## 改线原则

1. 先确认模块类型。
2. 再确认供电电压。
3. 再确认 `GND` 共地。
4. 最后确认信号线。

不要看到“灰度模块”就套用同一种接法。感为 `DAT + CLK`、亚博 UART、其他独立光电模块不是同一种接线。

## OLED

修改文件：

```text
User/Src/board_oled.c
```

如果更换 OLED 引脚，需要同步修改 SDA/SCL 的 pin、iomux 和端口读写函数。

## 按键

修改文件：

```text
User/Src/board_keys.c
```

如果更换按键引脚，需要同步修改按键宏和扫描逻辑。

## 蜂鸣器

修改文件：

```text
User/Src/board_buzzer.c
```

如果更换蜂鸣器引脚，需要同步修改输出端口和 pin。

## UART

修改文件：

```text
User/Src/board_uart.c
```

UART 接线注意：

- 模块 `TX` 接主控 `RX`。
- 模块 `RX` 接主控 `TX`。
- 必须共地。

## 感为灰度

修改文件：

```text
User/Src/digital_gray8.c
```

当前只讲：

```text
DAT -> SDA
CLK -> SCL
```

如果改线，只改 `digital_gray8.c` 里 SDA/SCL 相关宏。
