## 改线时改哪里

### OLED

文件：

- `User/Src/board_oled.c`

主要宏：

```c
#define OLED_SDA_PIN        DL_GPIO_PIN_0
#define OLED_SCL_PIN        DL_GPIO_PIN_1
#define OLED_SDA_IOMUX      IOMUX_PINCM1
#define OLED_SCL_IOMUX      IOMUX_PINCM2
```

如果 OLED 换到 GPIOB 或其他端口，还要修改这些函数里的 `GPIOA`：

- `oled_sda_high()`
- `oled_sda_low()`
- `oled_scl_high()`
- `oled_scl_low()`
- `BoardOled_Init()`

改完后测试：OLED 能显示启动文字或状态文字。

### 按键

文件：

- `User/Src/board_keys.c`

主要宏：

```c
#define KEY1_PIN       DL_GPIO_PIN_4
#define KEY1_IOMUX     IOMUX_PINCM9
#define KEY2_PIN       DL_GPIO_PIN_3
#define KEY2_IOMUX     IOMUX_PINCM8
#define KEY3_PIN       DL_GPIO_PIN_19

#define KEY4_IOMUX     IOMUX_PINCM51
#define KEY5_PIN       DL_GPIO_PIN_27
#define KEY5_IOMUX     IOMUX_PINCM58
```

如果按键从 GPIOA 换到 GPIOB，或者反过来，要同步修改：

- `BoardKeys_Task100Hz()`
- `g_pa_level` / `g_pb_level` 调试变量逻辑

改完后测试：逐个按键，检查 `BoardKeys_GetPressedMask()` 或 OLED/LED 测试显示。

### 普通直连 UART

文件：

- `User/Src/board_uart.c`

主要宏：

```c
#define BOARD_UART_INST        UART2
#define BOARD_UART_BAUD        115200U
#define BOARD_UART_TX_IOMUX    IOMUX_PINCM43
#define BOARD_UART_TX_PF       IOMUX_PINCM43_PF_UART2_TX
#define BOARD_UART_RX_IOMUX    IOMUX_PINCM44
#define BOARD_UART_RX_PF       IOMUX_PINCM44_PF_UART2_RX
```

如果换到另一个 UART 外设，需要同时改：

- `BOARD_UART_INST`
- TX/RX 的 IOMUX 宏
- TX/RX 的外设功能宏
- 文件底部的中断函数名
  - 当前：`void UART2_IRQHandler(void)`
  - 如果换 UART1，就改成：`void UART1_IRQHandler(void)`
- `BoardUart_Init()` 里的 NVIC 中断号
  - 当前：`UART2_INT_IRQn`

不要换到 `UART0`，因为 `UART0` 已经被 DCAR 内核占用。

改完后测试：

1. 编译烧录。
2. USB-TTL 接线：
   - 适配器 RXD -> 板子 TX
   - 适配器 TXD -> 板子 RX
   - 适配器 GND -> 板子 GND
3. 串口参数：`115200 8N1`
4. 发送 `PING123\r\n`，应收到 `RX:PING123\r\n`。
5. 连续发送 `A1\r\nB2\r\n`，应收到 `RX:A1\r\nRX:B2\r\n`。

### 感为科技 Gray8 4051 灰度传感器

文件：

- `User/Src/gray8.c`

主要宏：

```c
#define GRAY8_ADC_INST          ADC0
#define GRAY8_ADC_MEM           DL_ADC12_MEM_IDX_0
#define GRAY8_ADC_CHAN          DL_ADC12_INPUT_CHAN_4
#define GRAY8_OUT_IOMUX         IOMUX_PINCM56
#define GRAY8_ADDR_PORT         GPIOB
#define GRAY8_ADDR0_PIN         DL_GPIO_PIN_18
#define GRAY8_ADDR1_PIN         DL_GPIO_PIN_24
#define GRAY8_ADDR2_PIN         DL_GPIO_PIN_17
#define GRAY8_ADDR0_IOMUX       IOMUX_PINCM44
#define GRAY8_ADDR1_IOMUX       IOMUX_PINCM52
#define GRAY8_ADDR2_IOMUX       IOMUX_PINCM43
```

如果改 ADC 输入：

- 修改 `GRAY8_ADC_INST`
- 修改 ADC memory/channel 初始化
- 修改 `GRAY8_OUT_IOMUX`

如果改地址线：

- 修改 `GRAY8_ADDR_PORT`
- 修改 `GRAY8_ADDR0/1/2_PIN`
- 修改 `GRAY8_ADDR0/1/2_IOMUX`
- 如果三根地址线不在同一个 GPIO 端口，必须重写 `gray8_select()`，因为现在默认三根地址线都在 `GPIOB`。

改完后测试：

- 跑 Gray8 OLED 测试。
- 遮挡不同传感器，确认对应 raw 值变化。
- 传感器固定到最终高度后重新校准白/黑值。

## 改线检查清单

每次改引脚前：

1. 先看本文档和 `03_外设配置说明.md`。
2. 确认该引脚没有被 DCAR 内核占用。
3. 确认该引脚没有被其他用户模块占用。
4. 先只改模块内部的宏。
5. 如果 GPIO 端口变了，同步修改模块内所有 `GPIOA` / `GPIOB`。
6. 编译：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_user_gcc.ps1
```

7. 烧录：

```powershell
powershell -ExecutionPolicy Bypass -File .\flash_cmsis_dap.ps1
```

8. 跑该模块最小硬件测试。
9. 把测试结果写入 `C:\Users\qpzms\Desktop\STM32\TI\PROJECT_PROGRESS.md`。
