# 外设配置总说明

本文档记录当前这辆车教程里实际讲解的用户侧外设。历史分线方案不作为本车方案，不在本文档中列接线表。

## 2. 资源边界

下面这些资源属于核心系统或底层控制，不建议在外设教程里随意改：

| 资源 | 说明 |
|---|---|
| 电机 PWM/方向 | 由小车底层控制逻辑使用 |
| 编码器输入 | 由小车底层控制逻辑使用 |
| IMU/SPI | 由核心运动相关逻辑使用 |
| 调试/下载相关引脚 | 不要随意复用 |
| Flash 校准/授权区域 | 不要擦除 |

如果只是拍外设教程，不需要带学生改这些底层资源。

## 3. OLED

用途：

- 显示模式。
- 显示传感器状态。
- 显示调试信息。
- 在不接电脑时辅助判断车辆状态。

代码：

```text
User/Inc/board_oled.h
User/Src/board_oled.c
```

常用 API：

```c
void BoardOled_Init(void);
void BoardOled_Clear(void);
void BoardOled_SetLine(uint8_t line, const char *text);
void BoardOled_SetNumber(uint8_t line, const char *label, int32_t value);
void BoardOled_SetHex(uint8_t line, const char *label, uint32_t value);
void BoardOled_Task10Hz(void);
```

## 4. 按键

用途：

- 切换模式。
- 开始任务。
- 停止任务。
- 切换调试页面。

代码：

```text
User/Inc/board_keys.h
User/Src/board_keys.c
```

常用 API：

```c
void BoardKeys_Init(void);
void BoardKeys_Task100Hz(void);
uint8_t BoardKeys_GetPressedMask(void);
uint8_t BoardKeys_IsPressed(BoardKey key);
uint8_t BoardKeys_WasPressed(BoardKey key);
```

## 5. 蜂鸣器

用途：

- 上电提示。
- 模式切换提示。
- 错误提示。
- 任务完成提示。

代码：

```text
User/Inc/board_buzzer.h
User/Src/board_buzzer.c
```

常用 API：

```c
void BoardBuzzer_Init(void);
void BoardBuzzer_On(void);
void BoardBuzzer_Off(void);
void BoardBuzzer_Beep(uint16_t duration_ms);
void BoardBuzzer_BeepOk(void);
void BoardBuzzer_BeepError(void);
void BoardBuzzer_Task1kHz(void);
```

## 6. UART

用途：

- 串口调试。
- 外接 UART 传感器。
- 亚博智能灰度 UART 方案。

代码：

```text
User/Inc/board_uart.h
User/Src/board_uart.c
```

注意：

- UART 的 `TX/RX` 要交叉接。
- 模块和主控必须共地。
- 如果同时使用灰度 UART，就不要把同一组串口再给别的模块使用。

## 7. 感为灰度模块

当前本车教程按 `DAT + CLK` 数字通信方案讲。

代码：

```text
User/Inc/digital_gray8.h
User/Src/digital_gray8.c
```

拍摄口径：

```text
感为灰度这里只讲 DAT 和 CLK 数字通信，不讲历史分线方案，也不讲模拟扫描方案。
```

常用 API：

```c
void DigitalGray8_Init(void);
void DigitalGray8_SetAddress(uint8_t addr7);
uint8_t DigitalGray8_ScanAddress(uint8_t start_addr7, uint8_t end_addr7);
uint8_t DigitalGray8_Task10Hz(void);
uint8_t DigitalGray8_GetMask(void);
```

## 8. 亚博智能灰度 UART

当前亚博模块按 UART 单独讲，不和感为灰度混在一起。

代码：

```text
User/Inc/yabo_gray8_uart.h
User/Src/yabo_gray8_uart.c
```

拍摄口径：

```text
亚博智能模块是 UART 方案，重点是供电、共地、TX/RX 交叉接。它和感为 DAT/CLK 方案不是同一种接法。
```

## 9. 教程统一口径

后续拍摄和文档统一按下面说法：

- 这个系统基于官网/B站最小 TI 硬件系统。
- 点浮转接板是在最小系统基础上增加外设。
- 外设包括 OLED、按键、蜂鸣器、LED、供电扩展、灰度/光电模块。
- 灰度/光电部分只讲当前车辆实际采用的模块方案。
- 历史分线方案不放进本车教程。
- 接线前先确认供电，再确认共地，最后确认信号线。
