# 外设系统总览重录脚本

本文档用于重录“点浮 TI 转接板外设系统总览”视频。上一版不是录得不好，而是重点不够集中；这次要把“这个系统是在电赛 TI 最小硬件系统基础上扩展出来的”讲清楚，再讲转接板上安装了哪些外设，以及接线错误的风险在哪里。

## 0. 视频定位

这条视频不是重新讲 TI 最小系统接线，也不是逐个模块写代码教程。

这条视频只讲三件事：

1. 这个硬件系统是基于点浮官网/B站里“电赛 TI 最小硬件系统搭建”视频来的。
2. 在最小系统基础上，点浮转接板上又安装/接入了哪些外设。
3. 接线不能乱接，接错以后风险主要在 TI 核心板、电机、电源链路和外接模块。

如果最小系统视频已经讲过的内容，本视频不要重复展开，只提示同学去官网/B站看完整教程。

```text
这条视频我们不从零开始搭 TI 最小系统。TI 核心板、电机、电源、基础接线这些内容，点浮官网和 B 站已经有专门的视频教程，同学们可以先去看那个“电赛 TI 最小硬件系统搭建”的视频。

我们现在这个系统，是在最小硬件系统的基础上，加了点浮的转接板，再在转接板上接 OLED 显示屏、按键、蜂鸣器、LED 灯、电源转接模块、灰度传感器、光电管这些外设。你可以把它理解成：底层最小系统负责让车能供电、能驱动、能跑；这块转接板负责把常用外设整理好，让比赛调试和功能扩展更方便。
```

## 3. 点浮转接板上安装了哪些东西

这一段是本次重录的重点。拍摄时用手指着实物讲，不要只念表。

### 3.1 OLED 显示屏

现有教程：

```text
02_模块使用教程/01_OLED屏幕.md
```

硬件对应：

| 项目 | 内容 |
|---|---|
| 接口 | `H14` |
| 供电 | `5V`、`GND` |
| 信号 | `PA1 / OLED_SCL`，`PA0 / OLED_SDA` |
| 代码 | `board_oled.c/h` |

口播：

```text
这里是 OLED 显示屏。它主要用于调试，比如显示当前模式、传感器状态、灰度 mask、错误提示。比赛调车的时候，OLED 很重要，因为很多时候你不接电脑，也能直接从屏幕上看到车现在读到了什么。
```

拍摄动作：

- 指 OLED 位置。
- 指接口线。
- 如果屏幕能亮，拍一下显示内容。

### 3.2 五个按键

现有教程：

```text
02_模块使用教程/02_五个按键.md
```

硬件对应：

| 按键 | MCU 引脚 |
|---|---|
| `KEY1` | `PA4` |
| `KEY2` | `PA3` |
| `KEY3` | `PB19` |
| `KEY4` | `PB23` |
| `KEY5` | `PB27` |

口播：

```text
这边是五个按键。按键一般用来切换模式、开始任务、停止任务、切换参数页。我们把它做在转接板上，是为了比赛现场不用临时飞线，也不用每次都接电脑改程序。
```

拍摄动作：

- 手指依次按 1 到 5。
- 如果有 OLED，拍按键后屏幕变化。

### 3.3 蜂鸣器

现有教程：

```text
02_模块使用教程/03_蜂鸣器.md
```

硬件对应：

| 项目 | 内容 |
|---|---|
| 接口 | `H17` |
| 供电 | `5V`、`GND` |
| 控制脚 | `PA7 / BUZZER_IO` |
| 代码 | `board_buzzer.c/h` |

口播：

```text
这里是蜂鸣器。蜂鸣器不是为了好玩，它是一个状态提示器。比如上电成功响一下，进入比赛模式响一下，检测到错误可以响不同节奏。比赛现场很吵、很乱，有一个声音提示会比只看代码方便很多。
```

拍摄动作：

- 指蜂鸣器位置。
- 如果能响，拍短响一次。

### 3.4 LED 灯 / RGB 指示灯

硬件对应：

| 颜色 | MCU 引脚 |
|---|---|
| `RGB_R` | `PB3` |
| `RGB_G` | `PB4` |
| `RGB_B` | `PB5` |
| `GND` | `GND` |

口播：

```text
这里还有 LED 或 RGB 指示灯。它和蜂鸣器类似，也是状态提示用的。比如不同颜色可以表示待机、运行、错误、校准状态。当前教程重点先讲硬件位置和用途，后面如果需要，可以再单独补 LED 控制代码。
```

拍摄动作：

- 指 LED/RGB 位置。
- 如果能亮，拍不同状态。
- 如果现在没有程序控制，就只拍硬件位置，不要说已经做了完整 LED 功能。

### 3.5 电源转接模块

硬件对应：

| 接口/区域 | 作用 |
|---|---|
| `U3` | `VIN_ALL` 输入和 `GND` |
| `H25` | `3V3` 扩展 |
| `H26` | `5V` 扩展 |
| `H15/H24` | `GND` 扩展 |

口播：

```text
这部分是电源转接和扩展区域。它的作用是把常用的 5V、3.3V、GND 整理出来，方便接显示屏、传感器、调试模块。这里一定要注意：电源线不能乱接，3.3V 和 5V 不能混着来，正负也不能反。
```

拍摄动作：

- 指电源输入。
- 指 5V、3.3V、GND 扩展口。
- 用手强调正负不要反接。

### 3.6 灰度传感器 / 光电传感器

现有教程：

```text
02_模块使用教程/05_感为科技八路灰度.md
02_模块使用教程/06_亚博智能八路灰度_UART.md
02_模块使用教程/07_光电传感器现场验证.md
02_模块使用教程/08_光电管拍摄脚本与现场验证.md
```

口播：

```text
这一部分是灰度传感器或者光电传感器。它的作用是检测地面黑线和白底的变化，是循迹类任务里非常关键的输入。这里要注意，不同灰度模块通信方式不一样，所以不要把所有灰度模块都按一种接法接。
```

补充口播：

```text
这辆车不讲历史分线接到底板光电接口的方案。感为科技这部分按当前数字通信方案讲；亚博智能模块则单独按 UART 方案讲。具体接线看对应模块教程，不要看到灰度两个字就随便接。
```

拍摄动作：

- 指灰度/光电模块安装位置。
- 指信号线走向。
- 拍模块指示灯变化。

## 4. 接线风险一定要讲清楚

这一段是重点，语气要严肃一点。

建议口播：

```text
这里一定要提醒大家，不要乱接线。点浮转接板本身做了比较好的接口整理和保护，正常使用下不容易坏；但是这不代表大家可以随便接。接线接错以后，真正容易出问题的是 TI 核心板、电机、电机驱动、电源模块和外接传感器。

简单说，点浮转接板是为了帮你把系统接得更规整、更安全，但它不是让你乱插线的。尤其是电源正负、5V 和 3.3V、信号线和电源线，一定要看清楚再接。
```

如果你想说得更直接，可以这样讲：

```text
同学们要记住，转接板是保护和整理线路用的，不能把它理解成万能保险。接错线时，转接板通常比较抗造，但 TI 核心板和电机、电机驱动都有可能先出问题。所以不要觉得有转接板就可以乱接，接之前一定要确认 VCC、GND 和信号线。
```

建议屏幕字幕：

```text
不要乱接线：
1. 先确认 VCC/GND
2. 再确认 5V/3.3V
3. 最后确认信号线
接错可能损坏 TI 核心板、电机、驱动或传感器
```

## 8. 一镜到底口播版本

如果你想少剪辑，可以直接按下面这一版念：

```text
这一节我们讲点浮 TI 转接板上的外设系统。注意，这条视频不是从零搭建 TI 最小系统。TI 核心板、电机、电池、基础供电和最小系统接线，我们官网和 B 站已经有完整教程，同学们可以先去看那个视频。

现在这套硬件，是在最小 TI 硬件系统的基础上，加了点浮转接板，再在转接板上扩展一些比赛常用外设。也就是说，最小系统解决的是车能不能供电、能不能驱动、能不能运行；转接板解决的是外设接线更整齐、调试更方便、模块扩展更清楚。

我们先看转接板上有哪些东西。这里是 OLED 显示屏，它用来显示模式、传感器状态、灰度 mask 和调试信息。这里是五个按键，可以用来切换模式、开始任务、停止任务或者切换参数。这里是蜂鸣器，用来做声音提示，比如上电成功、进入运行模式、出现错误。这里还有 LED 或 RGB 指示灯，可以用不同颜色提示状态。

这一块是电源转接和扩展区域，常用的 5V、3.3V、GND 会从这里整理出来，方便接传感器和调试模块。但电源部分一定不能乱接，5V 和 3.3V 要分清楚，VCC 和 GND 要分清楚。

再看这里，这是灰度传感器或者光电传感器相关接口。它们主要用来检测黑线和白底，是循迹任务里的输入。不同灰度模块接法不一样，比如感为科技这边我们按数字量方案讲，亚博智能模块按 UART 方案讲，独立光电管又是另一种接法，所以不要看到灰度两个字就随便接。

最后一定要提醒大家，接线不能乱接。点浮转接板做了接口整理和一定保护，正常用不容易坏，但这不是让大家乱插线。接错以后，真正容易出问题的是 TI 核心板、电机、电机驱动、电源模块和外接传感器。接之前一定先确认 VCC、GND，再确认 5V 和 3.3V，最后确认信号线。

这条视频只是外设总览，让大家知道转接板上有哪些模块、每个模块大概做什么。具体某个外设怎么接线、代码怎么调用，后面看 OLED、按键、蜂鸣器、UART、灰度传感器这些单独教程。
```

## 9. 拍摄时不要说错的点

- 不要说这条视频会完整替代最小系统搭建教程。
- 不要把感为灰度和亚博 UART 灰度混成一种接法。
- 不要说“接错线也完全没事”。正确说法是：转接板比较抗造、做了保护，但接错仍可能损坏 TI 核心板、电机、驱动、电源模块或传感器。
- 不要说 LED 控制代码已经完整封装，除非你实际补了 LED 模块代码并测试过。
- 不要说光电管/灰度已经完成整车循迹验证，除非烧录和实车运行已经验证。
