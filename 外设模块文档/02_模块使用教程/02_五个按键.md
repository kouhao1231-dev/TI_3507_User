# 五个按键使用教程

## 1. 模块作用

按键用于用户输入，例如启动测试、切换页面、触发蜂鸣器、进入校准流程。

## 2. 当前引脚

| 按键 | MSPM0G3507 引脚 | 有效电平 |
|---|---|---|
| `KEY1` | `PA4` | 低电平 |
| `KEY2` | `PA3` | 低电平 |
| `KEY3` | `PB19` | 低电平 |
| `KEY4` | `PB23` | 低电平 |
| `KEY5` | `PB27` | 低电平 |

## 3. 需要的封装文件

| 文件 | 放入工程位置 |
|---|---|
| `04_封装源码/Inc/board_keys.h` | `User/Inc/board_keys.h` |
| `04_封装源码/Src/board_keys.c` | `User/Src/board_keys.c` |

## 4. 最小使用方法

```c
#include "board_keys.h"
#include "board_buzzer.h"

BoardKeys_Init();

for (;;) {
    BoardKeys_Task100Hz();

    if (BoardKeys_WasPressed(BOARD_KEY_1)) {
        BoardBuzzer_BeepOk();
    }
}
```

## 5. 常用 API

```c
void BoardKeys_Init(void);
void BoardKeys_Task100Hz(void);
uint8_t BoardKeys_GetPressedMask(void);
uint8_t BoardKeys_IsPressed(BoardKey key);
uint8_t BoardKeys_WasPressed(BoardKey key);
uint8_t BoardKeys_GetRawPressedMask(void);
```

说明：

- `BoardKeys_Task100Hz()` 建议每 10 ms 调用一次。
- `BoardKeys_IsPressed()` 表示当前是否按住。
- `BoardKeys_WasPressed()` 表示刚刚按下过一次，读完后会清除事件。

## 6. 测试方法

1. 初始化按键和 OLED。
2. 每次按键后，在 OLED 上显示按键编号。
3. 也可以按下后让蜂鸣器响一下。

## 7. 常见问题

### 按键一直显示按下

检查按键是否是低电平有效，或者引脚是否外部短接到 GND。

### 按键没反应

检查：

- 对应引脚是否接对。
- 是否调用 `BoardKeys_Init()`。
- 是否周期调用 `BoardKeys_Task100Hz()`。
