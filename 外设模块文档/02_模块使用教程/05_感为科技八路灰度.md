# 感为科技灰度模块接线与使用说明

本文档只讲当前这辆车实际采用的感为灰度接法：`DAT + CLK` 数字通信方案。

不要在本车教程里讲历史分线接到底板光电接口的方案；本车不考虑那种接线。也不要把它讲成模拟扫描方案。

## 1. 本车采用的接线

| 模块信号 | 接到主控 | 说明 |
|---|---|---|
| `VCC` | 按模块要求接电源 | 先确认模块标称电压 |
| `GND` | `GND` | 必须共地 |
| `DAT` | `SDA` 对应引脚 | 数据线 |
| `CLK` | `SCL` 对应引脚 | 时钟线 |

当前代码里按软件 IIC 思路读取：

```text
DAT 对应代码里的 SDA
CLK 对应代码里的 SCL
```

拍摄时只需要讲 `VCC/GND/DAT/CLK`，不要展开底板独立光电接口的历史分线方案。

## 2. 代码文件

当前灰度数字通信封装看这两个文件：

| 文件 | 作用 |
|---|---|
| `User/Inc/digital_gray8.h` | 灰度模块 API |
| `User/Src/digital_gray8.c` | 软件 IIC、地址探测、读取灰度状态 |

不要把本教程指向历史分线方案。

## 3. 常用 API

```c
void DigitalGray8_Init(void);
void DigitalGray8_SetAddress(uint8_t addr7);
uint8_t DigitalGray8_ScanAddress(uint8_t start_addr7, uint8_t end_addr7);
uint8_t DigitalGray8_Task10Hz(void);
uint8_t DigitalGray8_GetMask(void);
uint8_t DigitalGray8_IsOn(uint8_t channel);
```

最小使用流程：

```c
#include "digital_gray8.h"

DigitalGray8_Init();
DigitalGray8_SetAddress(DIGITAL_GRAY8_DEFAULT_ADDR);

for (;;) {
    DigitalGray8_Task10Hz();
    uint8_t mask = DigitalGray8_GetMask();
}
```

如果不确定模块地址，可以先用：

```c
DigitalGray8_ScanAddress(0x08, 0x77);
```

## 4. 拍摄时怎么讲

可以直接这样说：

```text
感为灰度这里我们不讲历史分线方案，这辆车不采用那种接法。我们只讲当前使用的 DAT 和 CLK 数字通信方案。接线时先确认 VCC 和 GND，再接 DAT 和 CLK。代码里 DAT 对应 SDA，CLK 对应 SCL，程序通过 digital_gray8.c 读取模块状态。
```

## 5. 现场验证

当前拍摄重点放在硬件现象：

1. 模块供电正常。
2. 模块指示灯有反应。
3. 手靠近、遮挡或放到黑白底面上时，模块灯有变化。
4. 程序烧录恢复后，再补拍 OLED 或串口显示 `mask` 的效果。

如果车当前烧录不上，不要在视频里说已经完成程序读取验证。
