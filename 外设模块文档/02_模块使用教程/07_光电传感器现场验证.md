# 光电传感器现场验证说明

当前这辆车不采用“8 路独立光电管分别接到底板光电接口”的接线方案。

这个文件只保留一个口径：本车教程不讲历史分线接法，也不展示对应 MCU 引脚表。实际巡线传感器请看当前使用的灰度模块教程：

- `05_感为科技八路灰度.md`
- `06_亚博智能八路灰度_UART.md`

## 拍摄时怎么说

```text
光电/灰度传感器这部分，我们只讲当前车辆实际使用的模块方案。历史上有一些独立光电管或者分线方案，但这辆车不采用，所以这里不展开接线表，避免同学照着错误方案去接。
```

## 可以拍什么

可以拍：

- 传感器安装位置。
- 模块上电指示灯。
- 手靠近、遮挡、黑白底切换时的灯光反应。
- 传感器在车头/底盘上的固定方式。

不要拍：

- 不要拍历史分线方案。
- 不要讲每一路对应哪个 MCU 引脚。
- 不要给学生展示历史分线表。

## 后续验证

等烧录恢复后，再补拍：

- 灰度模块状态在 OLED 上显示。
- 灰度模块状态通过串口输出。
- 小车根据灰度状态进行循迹或辅助定位。
