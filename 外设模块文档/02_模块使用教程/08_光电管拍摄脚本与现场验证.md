# 光电/灰度传感器拍摄脚本与现场验证

本文档给拍摄教程的人使用。当前这辆车不采用历史分线接法，所以拍摄时不要展示分线接到底板接口的方案，也不要讲每一路对应哪个 MCU 引脚。

本视频只拍三件事：

1. 传感器安装位置。
2. 模块供电和基础接线检查。
3. 手靠近、遮挡、黑白底切换时模块指示灯是否变化。

## 1. 开场口播

```text
这一段我们只讲当前车辆实际使用的光电/灰度传感器安装和基础验证。历史上有分线接到底板光电接口的方案，但这辆车不采用，所以这里不展示那种接线，也不让同学照着那种方式接。
```

## 2. 硬件清单

拍摄前把这些东西摆出来：

| 名称 | 说明 |
|---|---|
| 点浮 TI 小车底盘和转接板 | 展示传感器安装位置 |
| 当前实际使用的灰度/光电模块 | 只讲当前模块 |
| 连接线 | 只讲当前模块需要的线 |
| 电池或供电模块 | 用于上电验证 |
| 黑色胶带或黑线 | 模拟赛道黑线 |
| 白纸或浅色桌面 | 模拟白底 |

## 3. 安装位置怎么拍

镜头：

- 先拍车头或底盘前缘。
- 再拍传感器朝向。
- 最后拍线束固定。

口播：

```text
传感器安装在车头或底盘前缘，探头朝向地面，用来检测黑线和白底的反光变化。安装时要保证高度合适、方向一致，线束固定好，不能碰到轮子或电机。
```

## 4. 接线怎么讲

只讲当前模块实际需要的线。

如果是 `DAT + CLK` 灰度模块：

```text
这类模块重点看 VCC、GND、DAT、CLK。VCC 按模块要求接电源，GND 必须共地，DAT 是数据线，CLK 是时钟线。代码里 DAT 对应 SDA，CLK 对应 SCL。
```

如果是 UART 灰度模块：

```text
UART 模块重点看 VCC、GND、TX、RX。TX/RX 要交叉接，模块 TX 接主控 RX，模块 RX 接主控 TX。
```

不要出现：

- 不要讲历史分线方案。
- 不要讲某一路对应哪个底板接口。
- 不要讲某一路对应哪个 MCU 引脚。

## 5. 手触摸/遮挡看灯反应

这是本次最重要的可拍验证。

动作：

1. 拍模块上电后的指示灯。
2. 手慢慢靠近传感器。
3. 停 1 秒，让灯变化被拍清楚。
4. 手离开，再停 1 秒。
5. 用黑色胶带和白纸重复一次。

口播：

```text
现在车暂时不能完整烧录验证，所以我们先看硬件层面。手靠近或者黑白底变化时，模块指示灯会发生变化，说明传感器本身能感受到反光变化。后面烧录恢复以后，再补拍程序读取和整车运行效果。
```

## 6. 对着代码讲什么

如果讲感为 `DAT + CLK` 方案，只打开：

```text
User/Inc/digital_gray8.h
User/Src/digital_gray8.c
```

只讲：

- `DigitalGray8_Init()`
- `DigitalGray8_Task10Hz()`
- `DigitalGray8_GetMask()`
- `DAT` 对应 `SDA`
- `CLK` 对应 `SCL`

口播：

```text
代码里我们不走历史分线扫描，而是通过 digital_gray8 这个封装读取灰度模块状态。上层只需要拿到一个 mask，后续 OLED、串口或者运动逻辑都可以用这个状态。
```

| 镜头 | 内容 |
|---:|---|
