# 蜂鸣器使用教程

## 1. 模块作用

蜂鸣器用于提示状态，例如启动成功、按键触发、错误报警。

## 2. 当前引脚

| 信号 | MSPM0G3507 引脚 |
|---|---|
| `BUZZER_IO` | `PA7` |

## 3. 需要的封装文件

| 文件 | 放入工程位置 |
|---|---|
| `04_封装源码/Inc/board_buzzer.h` | `User/Inc/board_buzzer.h` |
| `04_封装源码/Src/board_buzzer.c` | `User/Src/board_buzzer.c` |

## 4. 最小使用方法

```c
#include "board_buzzer.h"

BoardBuzzer_Init();
BoardBuzzer_BeepOk();

for (;;) {
    BoardBuzzer_Task1kHz();
}
```

## 5. 常用 API

```c
void BoardBuzzer_Init(void);
void BoardBuzzer_On(void);
void BoardBuzzer_Off(void);
void BoardBuzzer_Beep(uint16_t duration_ms);
void BoardBuzzer_BeepOk(void);
void BoardBuzzer_BeepError(void);
void BoardBuzzer_Task1kHz(void);
uint8_t BoardBuzzer_IsOn(void);
```

说明：

- `BoardBuzzer_On()` 和 `BoardBuzzer_Off()` 是直接开关。
- `BoardBuzzer_Beep(ms)` 是定时响，必须周期调用 `BoardBuzzer_Task1kHz()`。
- 如果只是简单测试，可以先用 `On/Off`。

## 6. 测试方法

1. 上电后调用 `BoardBuzzer_BeepOk()`。
2. 如果听到短响，说明引脚配置正常。
3. 如果没有蜂鸣器，也可以临时把输出逻辑换到 LED 引脚验证高低电平。

## 7. 常见问题

### 蜂鸣器不响

检查：

- 蜂鸣器供电是否正确。
- `PA7` 是否接到蜂鸣器控制端。
- 蜂鸣器是有源还是无源。当前封装按 GPIO 开关方式写。
